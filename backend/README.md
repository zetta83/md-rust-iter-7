# backend

Лёгкий REST-бэкенд на [axum](https://github.com/tokio-rs/axum) для учебного проекта
Mini-Launchpad. Без базы данных — состояние читается напрямую из сети Solana по RPC
и десериализуется из PDA `OracleState` программы [`token_factory`](../programs/token_factory).

## Структура

```
src/
  main.rs        точка входа: .env, логирование, конфиг, роутер, запуск сервера, запуск price feed
  config.rs      Config::from_env() — чтение и валидация переменных окружения
  error.rs       AppError (thiserror) — маппинг ошибок в HTTP-статус и JSON
  oracle.rs      AppState, RPC-запрос и декодирование аккаунта OracleState
  routes.rs      сборка Router, обработчики /health и /oracle
  price_feed.rs  фоновая tokio-задача — имитация внешнего price feed (опционально)
```

Для декодирования аккаунта бэкенд не дублирует структуру `OracleState` вручную, а
подключает сам крейт `token_factory` как обычную библиотечную зависимость (с
фичей `cpi`, которая отключает генерацию Solana-энтрипойнта) и использует
`anchor_lang::AccountDeserialize` — то же самое, чем пользуются тесты программы.

## Переменные окружения

Смотри `.env.example`. Файл `.env` в корне `backend/` подхватывается автоматически
(`dotenvy`) при старте.

| Переменная            | Обязательна | Описание                                                        |
|------------------------|:-----------:|-------------------------------------------------------------------|
| `RPC_URL`              | да          | URL Solana JSON-RPC (например, `http://127.0.0.1:8899` для localnet) |
| `PROGRAM_ID`           | да          | Program id `token_factory` в этой сети — проверяется как владелец аккаунта оракула |
| `ORACLE_STATE_PUBKEY`  | да          | Адрес PDA `OracleState` (выводится `make init` / скриптом инициализации оракула) |
| `PORT`                 | нет         | Порт, на котором слушает сервер (по умолчанию `8080`)             |
| `ADMIN_KEYPAIR_PATH`   | нет         | Путь к keypair-файлу админа оракула — задать, чтобы включить фоновый price feed (см. ниже) |
| `PRICE_FEED_INTERVAL_SECS` | нет     | Период тиков price feed в секундах (по умолчанию `30`); учитывается только вместе с `ADMIN_KEYPAIR_PATH` |

Если обязательная переменная отсутствует или невалидна (например, `PROGRAM_ID` —
не валидный base58-адрес), процесс завершится при старте с понятным сообщением
об ошибке (`anyhow`).

## Запуск

```bash
cd backend
cp .env.example .env   # и заполнить ORACLE_STATE_PUBKEY своим значением
cargo run
```

Требуется поднятый и доступный по `RPC_URL` валидатор (`solana-test-validator`
для localnet или публичный RPC devnet) с задеплоенной программой `token_factory`
и уже инициализированным оракулом (инструкция `initialize`) — иначе `/oracle`
будет отвечать `404`.

## Эндпоинты

| Метод | Путь       | Описание                                                        |
|-------|------------|---------------------------------------------------------------------|
| `GET` | `/health`  | healthcheck, всегда `200 OK`                                        |
| `GET` | `/oracle`  | текущее состояние оракула                                           |

### `GET /health`

```json
{ "status": "ok" }
```

### `GET /oracle`

Успешный ответ (`200 OK`):

```json
{
  "admin": "5riFLEreN6jAox1AzjuxjwV2nraXatJpA3hQQZ5GPk9d",
  "price": 1000000,
  "decimals": 6,
  "last_updated_slot": 12345,
  "is_stale": false
}
```

`is_stale` — `true`, если `текущий_слот - last_updated_slot` превышает
`MAX_STALENESS_SLOTS` (100), ту же константу использует и сама программа при
проверке `get_price`.

Ошибки:

| Статус | Когда возникает                                                              |
|--------|--------------------------------------------------------------------------------|
| `404`  | аккаунт `ORACLE_STATE_PUBKEY` не найден в сети (оракул ещё не инициализирован) |
| `502`  | владелец аккаунта не совпадает с `PROGRAM_ID`, сбой RPC-запроса или не удалось декодировать данные аккаунта |

Тело ответа об ошибке (текст сообщения приходит из `thiserror` и всегда на английском):

```json
{ "error": "oracle account not found at the configured address" }
```

## Price feed (опционально)

Если задан `ADMIN_KEYPAIR_PATH`, при старте процесса запускается фоновая
tokio-задача (`src/price_feed.rs`), которая имитирует внешний price feed: раз в
`PRICE_FEED_INTERVAL_SECS` секунд она

1. читает текущую цену из `OracleState` (тем же кодом, что и `/oracle`);
2. случайно сдвигает её на величину до ±1% (в границах ±20%, которые сама
   программа проверяет в `update_price` — см. `programs/token_factory/src/instructions/update_price.rs`);
3. отправляет и подтверждает транзакцию `update_price`, подписанную keypair'ом
   из `ADMIN_KEYPAIR_PATH` (он должен совпадать с `admin` оракула, иначе
   программа отклонит вызов с `ConstraintHasOne`).

Задача не обязательна для сдачи задания и не является HTTP-эндпоинтом. Если
`ADMIN_KEYPAIR_PATH` не задан — она просто не запускается. Ошибка на отдельном
тике (RPC недоступен, оракул ещё не инициализирован и т.п.) логируется как
`WARN` и не останавливает ни задачу, ни сам сервер — следующая попытка будет
через `PRICE_FEED_INTERVAL_SECS`.
